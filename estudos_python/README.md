# 🐍 Exercícios de Python

Repositório com a resolução dos exercícios propostos no **Módulo 3** do canal
[Curso em Vídeo](https://www.youtube.com/@CursoemVideo), como parte da minha
preparação para conseguir meu primeiro estágio em Desenvolvimento de Software.

---

## 📌 Sobre

- Cada arquivo segue o padrão `ExerXX.py`, onde `XX` é o número do exercício original do curso.
- Arquivos que **não** seguem esse padrão contêm exercícios resolvidos fora do curso
  (ex: variações próprias, exercícios do LeetCode, ou sugestões feitas com apoio do Claude).
  Nesses casos, a origem é descrita no arquivo `ORIGEM.md`.
- Os exercícios estão organizados por tema conforme avanço no curso.

---

## 📂 Conteúdo por tema

| Exercícios | Tema                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 084 – 086  | Listas: armazenamento de múltiplos registros, busca de máximo/mínimo |
| 090 – 095  | Dicionários: estruturação de dados, chaves condicionais              |
| 096 - 100  | Funções: parâmetros, docstring, implementação

> Esta tabela será atualizada conforme novos exercícios forem adicionados.

---

## ✅ Como executar

Qualquer arquivo pode ser executado diretamente com Python 3:

```bash
python ExerXX.py
```

---

## 🧠 Observações de aprendizado

Alguns exercícios incluem comentários explicando decisões de lógica
(ex: por que uma estrutura de repetição foi usada de determinada forma).
Isso é intencional — o objetivo do repositório não é só resolver o exercício,
mas documentar o raciocínio por trás da solução.
