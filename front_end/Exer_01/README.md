# Loja de Produtos Esportivos 🏃‍♂️

Projeto de exercício desenvolvido durante o curso de **HTML e CSS da ORIGAMID**, com o objetivo de praticar conceitos fundamentais de estilização e estruturação de páginas web.

## 🎯 Objetivo do exercício

Este projeto foi criado para treinar:

- Uso de **CSS Grid** para organizar o layout dos produtos
- Manipulação de **cores** (paleta escura com destaques em laranja)
- Uso de **divs** e outras tags semânticas para estruturar o conteúdo
- Estilização de imagens, textos e espaçamentos

## 🛍️ Sobre o projeto

Um site simples simulando uma loja de produtos esportivos, exibindo um catálogo com:

- Meia Nike Everyday Lightweight (kit com 3 pares)
- Camiseta esportiva
- Tênis de corrida
- Hand Grip (fortalecedor de mãos)

Cada produto é exibido em um card contendo imagem, descrição e preço.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo
- **CSS3** — estilização e layout (Grid, cores, espaçamentos)

## 📁 Estrutura de arquivos

```
├── index.html
├── style.css
└── image/
    ├── kit-meia-nike-everyday-lightweight-c-3-unissex-sx7676-100.jpg
    ├── images.jpg
    ├── photo-1542291026-7eec264c27ff.avif
    └── premium_photo-1671028545869-718945152c70.avif
```

> ⚠️ Importante: as imagens precisam estar dentro de uma pasta chamada `image/` na raiz do projeto, pois é o caminho referenciado no `index.html`.

## 🚀 Como visualizar

1. Baixe ou clone os arquivos do projeto
2. Certifique-se de que a pasta `image/` contém as imagens dos produtos
3. Abra o arquivo `index.html` em qualquer navegador
