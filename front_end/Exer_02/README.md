# Bikcraft

Exercício desenvolvido durante o curso **Front-end Full-Stack** da Origamid, com o objetivo de treinar a construção de uma landing page utilizando HTML e CSS puro.

## 🎯 Objetivo do exercício

Praticar conceitos fundamentais de CSS e HTML, incluindo:

- **Flexbox** — usado no menu de navegação para alinhar os links horizontalmente;
- **Grid** — usado para estruturar a seção principal (texto + imagem) em duas colunas;
- **Position** — usado para posicionar o pequeno detalhe decorativo (`.detalhe`) de forma absoluta sobre o layout;
- **Estilização geral com CSS** — cores, tipografia, espaçamentos, botões e bordas arredondadas;
- **Uso semântico de tags HTML** — cabeçalhos, links, parágrafos e imagens organizados de forma estruturada.

## 🖥️ Estrutura da página

1. **Cabeçalho** — título "bikcraft" e menu de navegação (SOBRE, PRODUTOS, LOJAS, CONTATO);
2. **Seção principal (grid)** — texto de apresentação do produto "Nimbus Stark" ao lado da imagem da bicicleta;
3. **Seção de vantagens** — três cards destacando os diferenciais do produto (Motor Elétrico, Velocidade e Rastreador).

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, Grid Layout, Position)

## 📁 Arquivos

- `Index.html` — estrutura da página;
- `Style.css` — estilização;
- `nimbus1.jpg` — imagem da bicicleta usada na seção principal.

## 📌 Observação

Este projeto foi feito exclusivamente para fins de estudo, seguindo as instruções de um exercício prático do curso Origamid.
