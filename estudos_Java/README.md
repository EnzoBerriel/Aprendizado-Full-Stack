# Exercícios de Java

Repositório com a resolução de exercícios propostos pelo **CLAUDE IA** como parte da minha
preparação para conseguir meu primeiro estágio em Desenvolvimento de Software.

---

## 📌 Sobre

- Cada exercício aborda uma lógica diferente, e utiliza de diversos ferramentas, bem como as respectivas bibliotecas.
- Os exercícos possuem um nível de dificuldade crescente.
-Os exercícos estam dispostos em pastas com a seguinte padrão `Exer_XX`, onde `XX` representa sua respectiva numeração conforme a ordem cronológica e nível de dificuldade.

---
## ✅ Como executar

Qualquer arquivo pode ser executado diretamente com Python 3:

```bash
javac Exer_XX/Main.java
java Exer_XX.Main
```
---

## 🧠 Observações de aprendizado

Alguns exercícios incluem comentários explicando decisões de lógica
(ex: por que uma estrutura de repetição foi usada de determinada forma).
Isso é intencional — o objetivo do repositório não é só resolver o exercício,
mas documentar o raciocínio por trás da solução.
